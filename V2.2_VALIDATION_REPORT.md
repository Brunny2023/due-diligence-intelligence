## Production-readiness boundaries

The code and package are ready for a controlled publisher deployment but the following cannot be truthfully preconfigured from the repository: the real OpenRouter credential; the exact publisher-selected current production model identifier; Capafy’s actual hosted-secret mapping; live pricing/delivery fields; live category/tags; actual provider/downstream model data path; final support contact; the current native request-limit user-interface field; and deployed-platform test results. These are documented publisher actions, not unresolved code defects.

V2.2 intentionally has no background execution, request counter, persistent service, undocumented provider fallback, automatic model routing, browser automation, or production live-call test with an unavailable credential.
