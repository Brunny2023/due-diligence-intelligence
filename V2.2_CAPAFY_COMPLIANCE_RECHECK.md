## V2.2 behavioral boundaries

The V2.2 adapter uses OpenRouter’s documented OpenAI-compatible API shape and does not transmit user material until an explicit user-initiated inference call has an enabled external-data permission flag. Deterministic helpers remain offline. The adapter supports only a single configured OpenRouter path in this release; no browser use, scraping, auto-research, plugin, file-parser, tool-execution, streaming, automatic fallback, or automatic model routing is enabled. [2]

The package’s findings remain bounded by V2.1 evidence rules. Provider synthesis may assist with interpretation but cannot upgrade evidence status, reconcile contradictions without a documented basis, create numerical certainty, or make legal, financial, investment, tax, accounting, regulatory, or transaction decisions.

## Required publisher release gate

Before listing submission, the publisher must complete the following in the live interface: host/map the OpenRouter credential; select and test the exact production model; finalize OpenRouter and actual downstream-provider data disclosures; set US$19 monthly pricing and a 60 Current Period Request Limit if those terms remain intended; complete at least one fictional deployed connection test; populate a real support email; select live category/tag presets; enter platform test cases; and recheck the live Publisher Agreement, pricing, delivery, and data-handling terms.
